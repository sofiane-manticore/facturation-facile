GUIDE DE PRISE EN MAIN

[01]

1. AUCUNE DONNÉE EN LIGNE // 100% LOCAL

Cette application fonctionne exclusivement sur votre appareil. Aucune donnée personnelle, bancaire ou client n'est envoyée sur un serveur distant.

// Sauvegarde : Tout est stocké dans votre navigateur. Utilisez le bouton [SAVE] pour exporter votre fichier JSON.
[02]

2. CONFIGUREZ VOTRE PROFIL ÉMETTEUR

Cliquez sur [USER] PROFIL pour renseigner votre entreprise, SIRET, email, adresse et coordonnées bancaires (IBAN / BIC).

// Vos coordonnées seront automatiquement insérées par défaut sur chaque nouveau document.
[03]

3. ORGANISATION PAR PROJET

Chaque devis ou facture est rattaché à un Projet doté de son code couleur.

// Renommer un projet le synchronise instantanément sur tous ses devis et factures associés.
[04]

4. ÉDITION DIRECTE SUR LA PAGE A4

Cliquez directement sur n'importe quel texte ou montant de la feuille A4. Les totaux HT, TVA et TTC sont calculés instantanément.

// Activez ou masquez le RIB Bancaire, la ventilation Acompte/Solde ou le cadre Signature via le panneau d'options.
[05]

5. EXPORT VECTORIEL 1 PAGE A4

Cliquez sur [PDF] TÉLÉCHARGER pour obtenir un fichier PDF vectoriel calibré sur une seule page A4.
